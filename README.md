# 🧮 BMI Calculator

A simple **Body Mass Index (BMI)** calculator built with **HTML, CSS, and JavaScript**.  
This project provides a lightweight web app that allows users to input their height and weight, then instantly calculates and displays their BMI along with the health category.

## 🚀 Features
- Input height (cm) and weight (kg)
- Instant BMI calculation using JavaScript
- Categorizes BMI results:
  - Underweight
  - Normal weight
  - Overweight
  - Obese
- Responsive and clean UI
